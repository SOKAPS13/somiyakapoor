Abstract

Existing QoE predictors fail when users jump during playback — each jump flushes the buffer and breaks the stationary traffic assumptions that prior models rely on. This work introduces PB-QoE, a jump-aware pipeline that detects interaction intensity from encrypted traffic with 100% accuracy, then corrects QoE estimates via an interaction-dependent penalty — outperforming baselines across all tested bandwidth and jump conditions.


End-to-end encryption prevents network operators from accessing video quality metrics directly, forcing reliance on indirect traffic signals for QoE estimation. By extending state-of-the-art video fingerprinting techniques with a novel penalty model tailored to user jumping behaviour, PB-QoE delivers robust QoE predictions under the realistic, non-stationary conditions that interactive streaming creates.

PB-QoE Pipeline

01
Input
Encrypted Network Traffic Capture
Passive observation of HTTPS video streams — no packet decryption, no DPI. Only timing, size, and flow-level features are extracted from the encrypted traffic.
02
Detection
Jump Detection & Interaction Classification
A dedicated classifier identifies when a user has jumped (seeked) during playback, along with the intensity of interaction. Achieved 100% detection accuracy across all tested conditions — even under congested and low-bandwidth scenarios.
03
Base Prediction
CNN-Based QoE Regression
A convolutional neural network processes traffic fingerprints to generate a base QoE score. This module is trained on stationary (non-jumping) sessions and produces the initial quality estimate.
04
Correction
Interaction-Dependent Penalty Model
When jumps are detected, an interaction-dependent penalty is applied to the base QoE estimate. The penalty magnitude is calibrated to the detected interaction intensity, correcting for buffer-flush effects that break prior model assumptions.
05
Output
Corrected QoE Score
The final QoE prediction accounts for both the base video quality and the user's jumping behaviour — outperforming all baselines across the full range of tested bandwidth conditions and jump frequencies.

Key Findings

🎯
Perfect Jump Detection
The jump detector achieves 100% accuracy from encrypted traffic alone — identifying both the presence and intensity of user seeking behaviour without decrypting a single packet.
📉
Prior Models Break Under Jumps
Existing QoE predictors degrade significantly when users jump during playback. The buffer-flush effect violates the stationary assumptions these models were built on, leading to systematic errors.
🚀
+374% Over Baseline
PB-QoE outperforms the best baseline by up to 374% in prediction accuracy under interactive conditions — demonstrating the value of explicitly modelling user behaviour in the QoE estimation loop.
🔒
Fully Privacy-Preserving
The entire pipeline operates on encrypted traffic without any packet inspection. This makes PB-QoE deployable by network operators while preserving end-user privacy.
📡
Robust Across Network Conditions
PB-QoE maintains its advantage across all tested bandwidth levels and jump frequencies — from high-bandwidth sessions with rare jumps to congested streams with frequent interaction.
⚡
Practical for Real Deployment
The system remains accurate with limited training data and generalises across diverse streaming conditions, confirming its suitability for real-world network operator deployment.
